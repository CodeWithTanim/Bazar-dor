# BazarDor

A modern, responsive web application for tracking daily essential commodity prices across major markets in Bangladesh. BazarDor helps users explore current prices, compare market rates, and monitor daily price changes through a clean interface with Bengali localization.

**Live Demo:** [BazarDor](https://bazardor-lemon.vercel.app/)  
**GitHub Repository:** [CodeWithTanim/bazar-dor](https://github.com/CodeWithTanim/bazar-dor)

## Technologies Used

- **Next.js 16**: Application framework and routing.
- **React 19**: Component-based user interface.
- **TypeScript**: Type safety and maintainable code.
- **Tailwind CSS 4**: Responsive UI styling.
- **Better Auth**: Email/password and social authentication.
- **MongoDB**: Authentication data storage.
- **React Toastify**: Authentication and validation notifications.
- **React Marquee Text**: Scrolling price ticker.
- **BazarDor API**: Commodity and market price data.
- **Vercel**: Application deployment.

## Key Features

1. **Daily Price Ticker:** Displays product prices, units, and daily price changes in a continuously scrolling strip.

2. **Market Overview:** Highlights products with the highest daily price increases and decreases, alongside all available products.

3. **Category-Based Browsing:** Explore commodities by category and sort products by price in ascending or descending order.

4. **Product Details and Market Comparison:** View current prices, minimum and maximum prices, average prices, and market-wise price information.

5. **Authentication:** Register and sign in using email/password, Google, or GitHub through Better Auth.

6. **User Profile Management:** View account information and update profile details.

7. **Responsive Design:** Works across mobile phones, tablets, and desktop screens, with Bengali text and localized number formatting.

8. **Loading and Error States:** Includes loading skeletons and a custom 404 page for a smoother browsing experience.
